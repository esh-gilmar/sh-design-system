# Registro de decisões (ADR leve)

## DEC-001 · Identidade oficial versus convenções de produto

**Decisão:** 4 cores do Brandbook SH 2026 são oficiais; tokens adicionais são propostos até validação. A fonte Dax é normatizada pelo Brandbook, mas arquivos de fonte não podem ser distribuídos sem licenciamento.

**Status:** fundação proposta.

## DEC-002 · Separação SH Identity / SH Workspace

**Decisão:** preservar duas famílias visuais coerentes; login institucional não deve impor hero fotográfico a interfaces operacionais.

**Status:** proposta baseada em 7 capturas encaminhadas em conversa.

## DEC-003 · Plataforma de UI

**Decisão proposta:** tokens agnósticos de framework. Componentes futuros para React + TypeScript, preferencialmente Tailwind + Radix/shadcn quando tecnicamente adequado. CSS base permite integração com apps legados.

**Status:** proposta; adoção projeto a projeto.

## DEC-004 · Referências e privacidade

**Decisão:** não armazenar neste repositório público prints de sistemas internos, dados pessoais, documentos restritos, logotipos de uso não autorizado ou fontes licenciadas.

**Status:** em vigor.

## DEC-005 · Governança

**Decisão proposta:** versões semânticas, PR para mudanças de tokens aprovados e revisão visual; principais exemplos testados em desktop e mobile. Não alterar marca sem validação institucional.

**Status:** proposta.
